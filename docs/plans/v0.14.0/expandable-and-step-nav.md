## 展開小窓

利用規約などを小さく表示する、インラインスクロール領域。**Web Component**（JS クラス名は実装時に固定。例: `TwExpandable`）。

- **トグル**: 下部ボタンで高さを拡張し、同じボタンで折りたたみに戻せる
- 高さは **HTML 属性**で指定する（単位は実装時に固定。例: `collapsed-height` / `expanded-height`）
  - 展開先: 全部（内容の高さ） / 既定値 / ユーザー指定。指定方法は上記属性に乗せる
- 下部ボタンは **WC 内蔵**。開閉の文言は属性で上書き可
- 内容は slot（折りたたみ中も DOM に残し、領域内スクロール）
- Accordion の高さ制限は本版では入れない（要実装だが版未定。[unscheduled](../unscheduled/future-intents.md)）

## ステップナビ

お問い合わせの **入力 / 確認 / 完了** のような段階表示。ページ遷移するナビではない。**新 WC**（JS クラス名は実装時に固定。例: `TwStepNav`）。

- **表示のみ**（ラベル・番号・状態）。入力／確認／完了のパネルは持たない。出し分けは利用側
- `TwTabs` は使わない（内部流用もしない）
- ステップをクリックしても進まない（線形。先の段階へのジャンプなし）
- 「次へ／戻る」は持たない。フォーム側のボタンが段階を進める
- 各ステップに `status` を利用側が付ける。値は次の 3 つ（名称は実装時に固定してよい）
  - `current` — いまの段階
  - `done` — 済んだ段階
  - `not_yet` — まだ先の段階
- `status` が正。ホストメソッドでまとめて更新してよい（例: 指定インデックスを `current` にする）。メソッドが `done` / `not_yet` を自動では付け替えない
- Tabs 本体の改修は [pagination-and-tabs.md](./pagination-and-tabs.md)（同マイルストーン）

## 含まないもの

- Accordion の高さ制限
- パネルの出し分け、ルーティング、フォーム送信・バリデーション
- ステップのクリック遷移、内蔵の次へ／戻る
- `TwTabs` のラップ／内部利用
- a11y 本検討
