# v0.8.0 テスト仕様

対象: `apps/kitchen-sink` の **Vituum 維持＋Twig テンプレート化**。  
新しい Web Components の振る舞いロジックは追加しない。スタイル見た目の自動テスト（VRT）・Playwright E2E・a11y 本実装は行わない。

ドキュメントサイト体裁（FV・Getting Started 等）は **v0.9.0** のテスト仕様で扱う。本版は Twig 足場と既存ページ移行に限定する。  
実装ブランチは v0.9.0 と共通の `dev-v0.8.0` を使う想定。

関連: [roadmap.md](../../roadmap.md) v0.8.0 / [wishlist.md](../../wishlist.md) / [test.md](../../test.md)

計画上の補足（完了定義）:

- `@vituum/vite-plugin-twig`（または同等）を導入し、`vite` の plugins に Vituum + Twig がある
- 共通 layout / partial（少なくとも head・nav 相当）がある
- 旧 `src/pages/**/*.html` のページソースは残さず、Twig（`*.twig`）に移行する
- 既存 URL（trailing slash 含む）は build 後も到達できる
- CSS エントリ `/src/styles/main.css`（全部入り style）の読み込み経路は維持する

---

## Twig / Vituum 設定

### plugins と依存

- kitchen-sink が Twig 対応の Vite プラグインに依存する
- `vite.config` で Vituum と Twig を有効にする

#### 正常系

- `apps/kitchen-sink/package.json` に `@vituum/vite-plugin-twig`（または同等の Twig プラグイン）がある
- `vite.config`（`.js` / `.ts`）の plugins に `vituum` と Twig プラグインの両方が含まれる
- `npm run build:kitchen-sink`（root 経由）が成功する

#### 異常系

- Twig 未導入のまま pages だけ `.twig` にした状態、または HTML と Twig が混在して build が失敗する状態は不合格

---

## テンプレート構成

### layouts / partials

- ページ横断の HTML 骨格を layout に集約する
- ナビ・head（fonts / CSS）を partial または layout 内で共有する

#### 正常系

- `src/layouts/` 配下に base 相当の Twig がある（名称は `base.twig` でよい）
- head（charset / viewport / Google Fonts Inter+Noto Sans JP / `main.css`）が単一箇所に定義されている（全ページへのコピペ分散がない）
- グローバルナビが単一の partial または同等の共有断片にある
- 各ページ Twig が layout を extends（または include）して本文だけを差し替える

#### 異常系

- 各ページが doctype〜nav までフルコピーしたまま Twig 拡張子だけ変えた状態は不合格（共通化できていない）

---

## ページ移行

### 既存ルートの Twig 化

移行前に存在した次のルートは、Twig ソースから生成されること。

- `/`（ホーム）
- `/typography/`
- `/tokens/`
- `/svg-loader/`
- `/spinner/`
- `/button/`
- `/dropdown/`
- `/action-menu/`
- `/accordion/`
- `/modal/`
- `/avatar/`
- `/vertical-nav/`

#### 正常系

- 上記それぞれに対応する `src/pages/**/index.twig`（または Vituum が認識する同等パス）がある
- `apps/kitchen-sink/src/pages` 配下にページ用の `index.html` が残っていない（レイアウト用 HTML を置かない方針）
- `npm run build:kitchen-sink` 成功後、上記パスに相当する成果物が dist（または Vituum の出力先）に存在する
- コンポーネント系ページは従来どおり `@b4moss/the-wheels` を module script で読み込む（または layout の scripts block 経由で同等）

#### 異常系

- いずれかの既存ルートが build 成果物から消える、または 404 相当になる状態は不合格
- `.html` と `.twig` の二重定義でどちらが正か不明な状態は不合格

### ナビの現在地

- 共通ナビで、表示中ページに `aria-current="page"`（または同等の現在地表示）が付く

#### 正常系

- 例: `/button/` を開いたとき、Button 向けナビリンクに `aria-current="page"` がある
- 他ページのリンクには付かない（または付いていても一つに限る）

#### 異常系

- 全リンクに `aria-current` が付く、またはどのページでも付かない状態は不合格

## スタイル読み込み

### main.css

- ページは `/src/styles/main.css`（または build 後も同等に解決されるパス）を読む
- 中身は `@b4moss/the-wheels/style` への全部入り import を維持する

#### 正常系

- Twig 化後も head から `main.css` がリンクされる
- `main.css` が umbrella の `/style`（または同等の全部入り）を import している

#### 異常系

- スタイル未読のままページだけ移行した状態は不合格
