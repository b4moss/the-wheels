## TwButton（Issue #6）

### disable-on-click クリック後の寸法維持

- `disable-on-click` 有効時、クリックで内部 button を disabled にし、ラベル／アイコンを隠し、Spinner を表示する（既存）
- その際、**クリック直前の内部 `.button` の外形寸法を維持する**（横幅がシュリンクしない。高さについてもクリック前より小さくならない）
- 寸法の固定はコンテンツを隠す前に行う
- 検証は Vitest（happy-dom 等）で、内部 `button.button`（または同等の内部 button）に対する幅・高さ、または実装がセットする `minWidth` / `minHeight` で行う

#### 正常系

- 十分な長さのラベルを持つ `disable-on-click` ボタンを接続し、クリック前の内部 button 幅 `W0` を記録する → クリック後の幅 `W1` は `W1 >= W0`（シュリンクしない）
- 同上で高さ `H0` / `H1` について `H1 >= H0`
- クリック後もラベル（およびアイコン slot）は非表示、Spinner（`.button-spinner` 等）は表示される（v0.2.0 契約の回帰）
- クリック後、内部 button に寸法固定のためのインライン指定がある（例: `style.minWidth` / `style.minHeight` が空でない）、または同等の手段で `W0` / `H0` 以上が保証されている

#### 異常系

- `disable-on-click` なしでクリック → 内部 button のインライン寸法固定を行わない（幅・高さの意図的な固定が入らない）
- 初期から `disabled` のボタンをクリック → 追加の pending 遷移を起こさない（Spinner 二重生成なし）。寸法固定の「クリック時ロック」も新たに走らせない
- レイアウト未確定などでクリック前幅が `0` の場合 → 例外を投げない（固定をスキップするか、無害な値にする）

### TwButton#reset() と寸法ロックの解除

- `reset()` は `disable-on-click` 由来の disabled / Spinner を解除する（既存）
- あわせて、クリック時に付けた寸法固定（インライン `minWidth` / `minHeight` 等）を解除する

#### 正常系

- `disable-on-click` クリック後に `reset()` → Spinner が消え、ラベル表示が戻る
- 同上 → 内部 button からクリック時のインライン寸法固定が外れる（`minWidth` / `minHeight` が空、または未設定に戻る）
- 一度もクリックしていない状態で `reset()` → 例外なく、寸法スタイルも変えない

#### 異常系

- 初期から `disabled` 属性のみの要素で `reset()` → 作者由来の `disabled` は残し、誤って寸法固定を付けたり消したりしない（もともと固定していなければそのまま）

## Storybook（受け入れ）

自動テストは「アプリとスクリプトが成立すること」のスモークに限る。ストーリーのピクセル／色のアサートはしない。

### apps/storybook の存在と scripts

- モノレポに `apps/storybook`（workspace）がある
- root から開発サーバ・静的ビルドを起動できる

#### 正常系

- root の `package.json` に `dev:storybook` 相当の script がある
- root の `package.json` に `build:storybook` 相当の script がある
- `npm run build:storybook`（または同等）が成功し、静的成果物ディレクトリが生成される

#### 異常系

- `apps/storybook` が無い、または workspace に含まれない状態は不合格

### preview の読み込み経路

- kitchen-sink と同様、全部入り CSS と umbrella の WC 登録を使う

#### 正常系

- Storybook preview（またはグローバル設定）で `@b4moss/the-wheels/style`（または同等の全部入り CSS）を読み込む
- 同上で `@b4moss/the-wheels` を import し、デフォルト接頭辞の WC が登録される前提になっている

#### 異常系

- preview が style / components 未読のまま主要 WC ストーリーだけ置く構成は不合格（カタログとして見た目が出ない）

### 主要コンポーネント・カタログ

- 次の 9 WC について、それぞれ 1 つ以上のストーリーがあること
  - SVGLoader / Spinner / Button / Dropdown / ActionMenu / Accordion / Modal / Avatar / Vertical Nav

#### 正常系

- 上記 9 種それぞれに対応するストーリーファイル（またはストーリー定義）が存在する
- Button ストーリーに `disable-on-click`（または同等の pending 確認用）の例が含まれる
- カタログ対象に core ユーティリティ単体（`setPrefix` のみ等）を必須としない

#### 異常系

- 9 種のいずれかがストーリー未掲載のままリリース対象になる状態は不合格
