# v0.5.0 テスト仕様

対象: Avatar 向けピュア関数（書記素 / コントラスト）、`TwAvatar`、`TwVerticalNav`。  
スタイル（CSS）およびレイアウトユーティリティ（`.container` 等）の自動テストは行わない。カスタムイベントは発火しない。

関連仕様: [all.md](../components/all.md) / [avatar.md](../components/avatar.md) / [vertical_nav.md](../components/vertical_nav.md)

計画上の補足（仕様書が短い箇所の完了定義）:

- 書記素: `Intl.Segmenter`（`granularity: "grapheme"`）。未対応時は `Array.from(name)[0]`。空/`name` なし → `""`
- コントラスト: 解決済み背景色に対し `#000000` / `#ffffff` のどちらが高いか選ぶ（WCAG 2 相対輝度。目標 4.5:1、両方未達ならより高い方）
- `color`: `#rgb` / `#rrggbb`、または `var(--…)` を `getComputedStyle` で解決。不能なら `--tw-bg-button-optional`
- 画像モード: `image-path` ありで内側に縮小した `<img>`。失敗時はイニシャル表示へフォールバック
- デフォルトサイズ: `width` / `height` 未指定時は `40` px
- Vertical Nav: slot 内先頭インタラクティブ要素の `aria-current="page"` → ホストに `data-tw-nav-current`
- レイアウト CSS はデモ用最小（自動テスト対象外）

## Avatar helpers

### getFirstGrapheme(name: string)

- 引数から先頭の Unicode 書記素クラスタを1つ返す
- `Intl.Segmenter(undefined, { granularity: "grapheme" })` を優先する
- Segmenter が無い環境では `Array.from(name)[0]`（なければ `""`）にフォールバックする

#### 正常系

- `"山田太郎"` -> `"山"`
- `"Alice"` -> `"A"`
- `"🇯🇵"`（旗など複数コードポイントの絵文字クラスタ）-> 1クラスタとしてそのまま返る（`"🇯🇵"`）
- `"👨‍👩‍👧‍👦"`（ZWJ シーケンス）-> 1クラスタとしてそのまま返る

#### 異常系

- `""` -> `""`
- 空白のみ（例: `"   "`）-> 先頭書記素が空白ならその空白1クラスタ（トリムしない）。実装が「表示用に trim する」場合はテスト仕様を実装に合わせて更新する（本版の既定は **trim しない**）
- 非文字列を渡した場合の型は TypeScript 上 `string` 前提。ランタイムで `null` / `undefined` を受けた場合は `""` を返す（例外を投げない）

### parseColor(input: string, resolveVar?: (value: string) => string | null)

- 背景色文字列を RGB 成分（0–255）に正規化するヘルパー
- `#rgb` / `#rrggbb`（大文字小文字不問）を受け付ける
- `var(--…)` は `resolveVar`（または同等）で解決してからパースする

#### 正常系

- `"#000"` / `"#000000"` -> `{ r: 0, g: 0, b: 0 }`（または同等）
- `"#fff"` / `"#FFFFFF"` -> `{ r: 255, g: 255, b: 255 }`
- `"#e1e1e1"` -> 対応する RGB
- `"var(--tw-bg-button-optional)"` かつ resolve 結果が `"#e1e1e1"` -> その RGB

#### 異常系

- `""` / `"not-a-color"` / `"#gg0000"` -> `null`（または失敗を示す値）。例外は投げない
- `var(--unknown)` で resolve が `null` -> `null`

### relativeLuminance(rgb) / contrastRatio(a, b)

- WCAG 2.x の相対輝度およびコントラスト比を計算する

#### 正常系

- 黒 `{0,0,0}` の相対輝度はおおよそ `0`
- 白 `{255,255,255}` の相対輝度はおおよそ `1`
- 黒と白のコントラスト比はおおよそ `21`

#### 異常系

- 不正な RGB（範囲外）を渡した場合はクランプするか失敗を返す（例外なし）。実装はクランプを推奨

### pickContrastingTextColor(background: string, resolveVar?)

- 背景色に対し `#000000` と `#ffffff` のうちコントラスト比が高い方を返す
- 両方とも 4.5 未満でも、より高い方を返す

#### 正常系

- 背景 `"#ffffff"` / `"#e1e1e1"` -> `"#000000"`
- 背景 `"#000000"` / `"#3b3b3b"` -> `"#ffffff"`
- 背景が `var(--tw-bg-button-optional)` で解決できるとき -> 黒または白のいずれか（解決色に対して正しい方）

#### 異常系

- 背景がパース不能 -> デフォルト背景（`--tw-bg-button-optional` 相当）を仮定して選ぶか、`"#000000"` にフォールバックする（例外なし。実装はデフォルト背景仮定を推奨）

## TwAvatar

### data-tw-component の付与

- ホスト接続時に `data-tw-component="avatar"` を付与する（接頭辞変更後も固定）

#### 正常系

- `<tw-avatar>` を接続 -> `data-tw-component="avatar"` がある

### イニシャル表示（image-path なし）

- `name` の先頭書記素を描画する
- 背景は `color`、未指定時は `--tw-bg-button-optional` 相当
- 文字色は `pickContrastingTextColor` の結果

#### 正常系

- `name="山田"` -> 表示文字が `"山"`
- `name="😀テスト"` -> 表示が絵文字クラスタ（`"😀"`）
- `color` 未指定 -> 背景がデフォルト optional 色（トークンまたは計算結果と一致）
- `color="#000000"` -> 文字色が `"#ffffff"`（または白相当）
- `color="#ffffff"` -> 文字色が `"#000000"`（または黒相当）

#### 異常系

- `name` 未設定または `name=""` -> 表示文字は `""`（仮文字 `?` 等は出さない）。例外なし
- `color="nope"` -> デフォルト背景にフォールバック（例外なし）

### 画像表示（image-path あり）

- 内部に `<img>` を描画し、`alt` を透過する
- 画像はホストより小さくし、背景が枠のように見える
- 読み込み失敗時はイニシャル表示にフォールバックする

#### 正常系

- `image-path` に有効 URL、`alt="User"` -> `img[src]` と `img[alt="User"]` がある
- 画像モードでもホスト背景色（`color` またはデフォルト）が設定されている

#### 異常系

- `image-path` の読み込みが失敗（error）-> `img` をやめ（または隠し）、`name` 由来のイニシャル表示に切り替わる。例外なし
- `image-path=""` -> 画像モードにせずイニシャル経路（`name` があれば）

### サイズ（width / height）

- 属性は px 指定。未指定時は両方 `40`

#### 正常系

- 未指定 -> ホスト（またはルート）の幅・高さが 40px 相当
- `width="64"` `height="64"` -> 64px 相当
- `width="48"` のみ -> 幅 48、高さは 40（または幅に合わせる）。本版の既定: **未指定側は 40**

#### 異常系

- `width="-1"` / `width="abc"` -> 当該寸法はデフォルト 40 にフォールバック（例外なし）

## TwVerticalNav

### data-tw-component の付与

- ホスト接続時に `data-tw-component="vertical-nav"` を付与する

#### 正常系

- `<tw-vertical-nav>` を接続 -> `data-tw-component="vertical-nav"` がある

### デフォルト slot（薄いラッパー）

- ホスト自身は `a` / `button` を新規描画しない
- 利用側が渡したインタラクティブ要素をそのまま（または投影して）保持する

#### 正常系

- 子に `<a href="/">Home</a>` を置いて接続 -> ホスト配下にその `a` が存在する（ホストが別の `a` を増やさない）
- 子に `<button type="button">` でも同様

#### 異常系

- 子が空 -> 例外なし（空のラッパー）
- インタラクティブ要素が複数ある -> 状態同期の対象は先頭のみ（列挙・分割しない）

### aria-current と data-tw-nav-current の同期

- slot 内先頭のインタラクティブ要素（`a` / `button` 等）の `aria-current="page"` を見て、ホストに `data-tw-nav-current` を付与する
- 値が無い／外れたらホストから `data-tw-nav-current` を除去する
- 動的変更にも追従する（MutationObserver または同等）

#### 正常系

- 接続時に子が `aria-current="page"` -> ホストに `data-tw-nav-current` がある
- 接続時に `aria-current` なし -> ホストに `data-tw-nav-current` がない
- 後から子に `aria-current="page"` を付ける -> ホストに付与される
- 後から子の `aria-current` を外す -> ホストから除去される

#### 異常系

- `aria-current="true"` や `"location"` など `"page"` 以外 -> `data-tw-nav-current` は付けない（本版は `"page"` のみ）
- 子要素が入れ替わった場合も、新しい先頭要素の状態に再同期する（例外なし）
