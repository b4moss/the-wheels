# v0.9.0 テスト仕様

対象: `apps/kitchen-sink` を **ドキュメントサイトとして読める体裁**に整えること（kitchen-sink 拡張。別 SSG / CMS は使わない）。  
前提として v0.8.0 の Twig 化が済んでいること。実装ブランチは v0.8.0 と共通の `dev-v0.8.0` を使う想定。

新しい Web Components の振る舞いロジックは追加しない。スタイル見た目の自動テスト（VRT）・Playwright E2E・a11y 本実装は行わない。

関連: [roadmap.md](../../roadmap.md) v0.9.0 / [wishlist.md](../../wishlist.md) / [test.md](../../test.md) / [v0.8.0 テスト仕様](./v0.8.0.md)

計画上の補足（完了定義）:

- トップ `/` に FV（参照リポ由来の `main-visual.png` を kitchen-sink 内に配置して表示）
- `/getting-started/` と `/components/` を追加
- 共通ナビに上記と既存デモへの導線がある
- Storybook との役割分担をサイト上に明記する
- パッケージ版は両マイルストーン同梱のため **0.9.0** に揃える（計画どおり）

---

## トップ（`/`）

### ヒーロー / FV

- トップはドキュメント入り口として、ブランドと FV が一画面の主構成になる
- FV 画像は参照リポ `the-wheels/dev/src/assets/img/home/main-visual.png` を kitchen-sink にコピーしたものを使う（プレースホルダ不可）

#### 正常系

- `apps/kitchen-sink` 配下（例: `src/assets/img/main-visual.png`）に FV 画像ファイルがある
- `/` のマークアップから当該画像が参照され、build 後も画像が成果物に含まれる（または Vite が解決する）
- `/` に製品名（The Wheels）がヒーロー級で示される（ナビ文言だけがブランド信号、にならない）
- `/` から Getting Started および Components（一覧）への導線リンクがある

#### 異常系

- FV が外部 URL のみ・ファイル未同梱で本番相当 build で欠ける状態は不合格
- トップが旧「ページ一覧のみ」のままで FV・導入導線が無い状態は不合格

### Storybook との役割

- 説明・導入・デモ導線は kitchen-sink、カタログは Storybook、と利用者が分かる一文がある

#### 正常系

- `/` または Getting Started のいずれかに、Storybook がコンポーネントカタログであること、kitchen-sink が説明・デモ導線であることが書かれている
- Storybook の起動方法（例: `npm run dev:storybook`）への案内がある

#### 異常系

- Storybook に言及が無く、カタログとの役割が分からない状態は不合格（本版の合格条件）

---

## Getting Started（`/getting-started/`）

### 導入手順ページ

- install と style / JS の最低限の使い方を載せる

#### 正常系

- `src/pages/getting-started/` 相当の Twig がある
- `npm run build:kitchen-sink` 後、`/getting-started/` に相当する成果物がある
- ページ本文に次が含まれる（文言は前後してよい）
  - パッケージ名 `@b4moss/the-wheels`（または install 例）
  - CSS の `@b4moss/the-wheels/style`（または同等の全部入り import）
  - JS の umbrella import
  - `setPrefix` をコンポーネント import **より前**に呼ぶ注意
- 共通ナビから `/getting-started/` へリンクできる

#### 異常系

- ページファイルはあるが上記の導入要素が欠けている状態は不合格

---

## Components 一覧（`/components/`）

### デモへのインデックス

- 既存のコンポーネント／トークン系デモへの一覧リンクを置く

#### 正常系

- `src/pages/components/` 相当の Twig がある
- build 後 `/components/` に相当する成果物がある
- 次のデモへのリンクがある（ラベルは人間可読でよい）
  - SVGLoader / Spinner / Button / Dropdown / ActionMenu / Accordion / Modal / Avatar / Vertical Nav
  - Typography / Tokens（スタイル確認）
- 共通ナビから `/components/` へリンクできる

#### 異常系

- 9 WC のいずれか、または Typography / Tokens が一覧から欠ける状態は不合格

## 共通ナビ

### ドキュメント向けリンクの統合

- v0.8.0 で共通化したナビに、ドキュメント用リンクを含める

#### 正常系

- ナビに Home（`/`）、Getting Started、Components、および既存デモ（または Components 経由に集約する場合は主要入口）へのリンク方針が一貫している
  - 最低限: `/`・`/getting-started/`・`/components/` がナビから辿れる
- 現在ページに `aria-current="page"` が付く（v0.8.0 契約の継続）

#### 異常系

- Getting Started / Components がサイト内のどこからもリンクされていない状態は不合格

## 既存デモの回帰

### URL 維持

- v0.8.0 で移行した既存デモ URL が、体裁追加後も build で残る

#### 正常系

- `/typography/` `/tokens/` `/svg-loader/` `/spinner/` `/button/` `/dropdown/` `/action-menu/` `/accordion/` `/modal/` `/avatar/` `/vertical-nav/` が build 成果物に存在する

#### 異常系

- ドキュメントページ追加に伴い既存デモが欠落する状態は不合格
