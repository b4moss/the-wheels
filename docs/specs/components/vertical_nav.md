# コンポーネント: Vertical Nav 仕様書

- Web Component として実装する（Light DOM）
- 縦方向のナビゲーションリスト
- 内部は可能な限りセマンティックな要素で描画する（例: `nav` / `ul` / `li` / `a`）
- a11y の詳細は後日検討。追加属性は可能な限り不要にする

## slot

- ナビ項目を slot 列挙で渡す
- 項目内にアイコンを置く場合は SVGLoader を利用する

## 振る舞い（初期）

- 現在地（アクティブ項目）を示せるようにする（属性またはクラスは実装時に決める）
- ネスト（サブメニュー）の要否は後日検討
