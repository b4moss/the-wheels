# コンポーネント: Modal 仕様書

- Web Component として実装する（Light DOM）
- JS クラス名: `TwModal`
- ネイティブの `<dialog>` 要素を採用する
- 内部は可能な限りセマンティックな要素で描画する
- a11y の詳細は後日検討。追加属性は可能な限り不要にする

## slot

- `header`
- `content`
- `footer`
- デフォルト slot は使わない

## 開く手段

- ホストメソッドとして `showModal()` を公開する（ネイティブ `<dialog>` に寄せる）
- 開くボタンは利用側が当該メソッドを呼ぶ

## 閉じる手段

- ホストメソッドとして `close()` を公開する（`<dialog>` に合わせる）
- デフォルトで、header 右上に閉じるボタン（×）を置く
- バックドロップクリックでも閉じる
- footer などにユーザーが任意に追加した要素からも閉じられるようにする
  - 閉じたい要素に `data-tw-modal-close` 属性を付ける

## レイアウト・サイズ

- バックドロップを表示し、背面スクロールをロックする
- ビューポートをはみ出さない
  - ビューポートに達したときは、content 内を `overflow: scroll` とする
- 初期描画後は幅・高さを固定し、コンテンツの増減は content 内スクロールで吸収する（カクつかせないため）
