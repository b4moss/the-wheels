# TwModal テスト仕様

関連仕様: [specs/components/modal.md](../../specs/components/modal.md)  
共通前提: [tests/e2e.md](../e2e.md)

- ホストメソッド `showModal()` で内部 `<dialog>` を開く
- ×（`data-tw-modal-close`）または同等の閉じ操作で閉じる
- バックドロップ相当の操作でも閉じる

対象ページ: `/modal/`

## テスト：正常系

- 開く操作で dialog／モーダル内容が表示される
- ×（または同等）で非表示になる
- バックドロップ相当の操作で閉じる

## テスト: 異常系

- 既に閉じている状態で閉じ操作しても、例外なく閉じたまま
- 閉じたあと同一ページ内で再オープンできる
- 開いた状態で再度開く操作をしても例外なく開いたまま
