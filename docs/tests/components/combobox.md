# TwCombobox テスト仕様

関連仕様: [specs/components/combobox.md](../../specs/components/combobox.md)  
共通前提: [tests/e2e.md](../e2e.md)

## TwCombobox（static）

- `mode` 未指定（`static`）。メモリ内 `options` をクライアント側でフィルタする
- 開くと検索欄とオプションが見える。選択でデモの value 表示が更新される

対象ページ: `/combobox/`（`#cb-static`）

### テスト：正常系

- 開くと検索欄とオプションが見える
- 検索入力で表示件数が減る（一致なしなら空状態）
- オプション選択で選択表示／value 表示が更新される

### テスト: 異常系

- 空クエリに戻すと、件数がある状態に戻る
- 一致なしの検索後もホストが例外なく操作可能である
- disabled デモがある場合は選択できず、例外なし（デモが無ければこの項は対象外）

## TwCombobox（async）

- `mode="async"`。リスト領域に InfiniteScroll を載せ、下端スクロールで追加ロードする
- 開いた直後はリストの先頭側が見える（末尾だけが見えている状態にならない）

対象ページ: `/combobox/`（`#cb-async`）

### テスト：正常系

- 開いた直後、リストの先頭側が見える
- 下端付近までスクロールすると件数が増える
- 閉じる操作で panel が閉じる

### テスト: 異常系

- 開閉を繰り返しても先頭表示が破綻しない（末尾ジャンプしない）
- 追加ロード後もホストが例外なく操作可能である

## TwCombobox（hybrid）

- `mode="hybrid"`。静的 options と非同期取得を併用する
- 開くとリストが見え、先頭側が表示される

対象ページ: `/combobox/`（`#cb-hybrid`）

### テスト：正常系

- 開くとリストが見え、先頭側が表示される
- 検索入力が例外なく動作する
- スクロールが例外なく動作する

### テスト: 異常系

- 開閉後も先頭表示が破綻しない
- 検索後もホストが例外なく操作可能である
